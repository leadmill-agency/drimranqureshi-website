# drimranqureshi.com — Website

The website for Dr. Imran Qureshi, D.O. — interventional pain management, Katy, TX.

## What this is

A fast, hand-built static website. Every page is a single self-contained HTML file — there is no database, no plugins, and nothing to update or maintain for security.

## How it goes live

This repository is connected to Vercel (the hosting service). Any change saved ("committed") to the `main` branch automatically publishes to https://www.drimranqureshi.com within about a minute.

## Making changes

- Small text changes can be made directly on GitHub.com (open the page file → pencil icon → edit → Commit changes). Only edit the words between tags — don't change anything inside `< >` angle brackets.
- For anything larger (new pages, design changes, the address update), have a web developer make the change — any developer can work with this repository.

## Key files

| File / folder | What it is |
|---|---|
| `index.html` | The homepage |
| `treatments/` | One page per treatment |
| `blog/` | Patient education articles |
| `images/` | Photos used on the site |
| `sitemap.xml`, `robots.txt` | Search-engine files — leave as-is |
| `vercel.json` | Hosting configuration — leave as-is |
